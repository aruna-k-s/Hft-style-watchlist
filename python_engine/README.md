# Python Engine Module

This module contains the core trading logic: signal processing, scoring, strategy, risk management, and execution.

## Files

- `main.py`: Orchestrator
- `signal_engine.py`: Feature calculations
- `scoring.py`: Ranking logic
- `strategy.py`: Trade decision engine
- `risk_manager.py`: Risk controls
- `execution_engine.py`: Trade execution
- `portfolio.py`: Portfolio management
- `logger.py`: Trade logging
- `backtester.py`: Backtesting framework
- `config.py`: Configuration constants

## Phases Implemented

- **Phase 1**: Basic signal processing
- **Phase 2**: Advanced signals with normalization and time-based scoring
- **Phase 3**: Complete trading system with strategy and risk
- **Phase 4**: Production features with config management

## Usage

```bash
cd python_engine
python3 main.py
```

## Configuration

See config.yaml for settings.
